ug uses a flat subcommand model (no clap derive — manual arg parsing).

index.json = indexed-tree.json (output of ug index) graph.json = output of ug graph ugdb/ = OverGraph embedded DB directory ~/.ug/ = project home directory

When --dest overgraph,neo4j is specified, both backends are opened as a StoreSet. Writes fan out to all stores; reads pick the primary.

Pipeline & Schemas

5.1 Pipeline Flow

ug index

Source files → indexed-tree.json (FileNode[] + FolderNode[] + dependencies)

ug graph

indexed-tree.json → graph.json (GraphNode[] + GraphEdge[] + stats)

ug ingest

graph.json → ugdb/Neo4j (embedded nodes + edges + FTS)

One-step: ug gen runs index → graph → ingest sequentially.
Step-by-step: ug index && ug graph && ug ingest.
With viz: ug gen --serve or ug serve.

5.2 index.json Schema (IndexResult)

FieldTypeContents
filesVec<FileNode>One per source file. Contains parsed symbols, imports, exports
foldersVec<FolderNode>File-system folder hierarchy with classification, README summaries
dependenciesVec<Dependency>From package.json
statsIndexStatstotalFiles, cachedFiles, totalSymbols, totalFolders, totalLines, indexingTimeMs, lastIndexedAt, repoRoot

5.3 graph.json Schema (GraphData)

FieldTypeContents
nodesVec<GraphNode>All symbols + files + folders + deps. Id format: {type}:{file}:{line}:{name}
edgesVec<GraphEdge>Directed edges. Types: Calls, Extends, Implements, References, Contains, Imports, Exports, Requires, Uses, DependsOn
statsOption<IndexStats>Copied from index.json for self-contained graph

5.4 Pipeline Steps

1. Index (indexer.rs)

Discovers files with supported extensions via scan_files(). For each file: tree-sitter parse → symbol extraction → import/export resolution. Supported languages: Rust, TypeScript/TSX, JavaScript, Python, Java, Markdown, PDF, Office docs. Cache: blake3 content hashes in cache.json. Output: indexed-tree.json.

2. Graph (graph.rs)

Reads IndexResult. Creates folder nodes → file nodes → symbol nodes. Resolves cross-file imports (path joins, extension permutations, basename fallback). Creates edges: Calls, Extends, Implements, References, Contains, Imports, Exports, Requires, Uses, DependsOn. Output: graph.json.

3. Ingest (storage/ingest.rs)

Reads GraphData, builds embedding text for each node (name + signature + docstring + related names + folder context + source snippet). Generates sparse keyword vectors. Incremental: diffs incoming vs stored nodes by content hash. Embeds only new/changed nodes in batches. Upserts nodes + edges to all configured backends. Output: embedded nodes and edges in ugdb/ or Neo4j.

$ ug gen -i ./my-repo --serve
▸ indexing    9.27s
▸ graph build 264ms
▸ embeddings  618s
▸ node write  993ms
▸ edge write  215ms
▸ listening on http://127.0.0.1:8080
